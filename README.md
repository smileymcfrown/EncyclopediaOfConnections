# The Encyclopaedia of Connections

All the ways to connect things. This is a beginner-friendly reference for hobbyist makers
(3D printing, robotics, CNC, woodwork and general tinkering). It covers every way to join,
move, lock and adjust parts, and has a guided finder that turns plain questions into a
shortlist of options. Each option has its proper name, so you can learn more.

**Status: Beta, being built.** There are 409 connection types in 31 families. Each has a page in
[`content/entries/`](content/entries/), and the finder is tested in
[`research/finder-test/`](research/finder-test/). Anything nobody has confirmed yet is marked
**⚑ needs confirming**. Corrections are welcome: see
[`research/needs-confirming.md`](research/needs-confirming.md) and
[CONTRIBUTING.md](CONTRIBUTING.md).

- [`PROJECT.md`](PROJECT.md): vision, requests, decisions, roadmap and current status
- [`content/`](content/): the entry pages and their format
- [`research/`](research/): the research runs, the finder test, and the finder tags
- [`tools/`](tools/): the scripts that make and check the entry pages
